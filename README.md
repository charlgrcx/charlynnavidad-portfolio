# Charlyn Grace Navidad - Creative Portfolio

- index.html  : the page structure and text (HTML)
- css/styles.css : colors, fonts, layout, animations (CSS)
- js/main.js  : content lists (top of file) + interactions (JavaScript)
- assets/     : fonts, images, photography, video

Run locally: open the folder in VS Code, install "Live Server", right-click index.html > Open with Live Server.
