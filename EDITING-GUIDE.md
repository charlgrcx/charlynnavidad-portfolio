# Quick editing guide (short version)

The full step-by-step guide is the "How to Edit Your Portfolio Website" doc.

| To change | Open | Press Ctrl+F and search |
|---|---|---|
| About, Awards, Contact, footer text | index.html | `EDIT` |
| Project cards and images | js/main.js | `var PROJECTS` |
| Photography (20 photos) | js/main.js | `var PHOTOS`, then `// Photo 7` |
| Product photos (5) | js/main.js | `var PRODUCTS` |
| Videos (2) | js/main.js | `var VIDEOS` |

Rules: change only words and file names. Keep every quote ' ' and comma. Never edit
style="..." or class="...", css/styles.css, or PART 2 / PART 3 of main.js.
File names: lowercase, no spaces (photo-07.jpg). Save (Ctrl+S), then refresh (Ctrl+Shift+R).
